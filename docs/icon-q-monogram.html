Q monogram — light colourways

The Q monogram from the proposal, recoloured into lighter, softer schemes. Each tile pairs a pale squircle with a deeper tone of the same hue for the glyph, so contrast survives the drop to 16 px. Hex values are shown so you can pick a direction.

Glow mirrors the "Glow" name but should be subtle at small sizes.

Notes. Light squircles read well in a light dock and also stand out on a dark desktop, so a single light master can cover both.

If you want a true dark-dock master as well, the same hues work inverted: keep the glyph colour as the squircle fill and use a near-white glyph.

Before shipping, each colourway still needs the full PNG ladder 16 32 64 128 256 512, a monochrome bar/tray variant, and a hand-tuned 16 px pass.
